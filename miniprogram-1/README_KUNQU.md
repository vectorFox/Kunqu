# 昆曲严肃游戏 - 游园惊梦

## 项目简介

这是一个基于微信小程序的昆曲文化传播严肃游戏，通过互动剧情、知识问答等形式，让用户在愉快的体验中感受和理解昆曲的音乐、服饰、人物与美学体系。

## 项目结构

```
miniprogram/
├── pages/              # 页面目录
│   ├── menu/          # 主菜单页面
│   ├── story/         # 剧情游戏页面
│   ├── quiz/          # 问答页面
│   ├── archive/        # 学习档案页面
│   ├── settings/      # 设置页面
│   └── admin/          # 管理后台页面
├── utils/              # 工具模块
│   ├── db.js          # 数据库操作封装
│   ├── story.js       # 剧情管理模块
│   └── quiz.js        # 问答管理模块
└── app.js              # 小程序入口

cloudfunctions/         # 云函数目录
└── quickstartFunctions/
```

## 核心功能

### 1. 剧情模块
- 脚本化剧情设计，支持JSON格式的剧情脚本
- 分支选择系统，根据玩家选择影响剧情走向
- 状态机机制，管理游戏状态和变量（理解值、好感值、积分等）
- 多结局系统，根据游戏变量触发不同结局

### 2. 问答模块
- 题库管理系统，支持分类和随机出题
- 多种题型：单选题、判断题
- 即时反馈机制，答题后显示解析
- 答题历史记录和正确率统计

### 3. 数据存档模块
- 用户进度自动保存
- 学习档案记录（已识别角色、答题记录）
- 云数据库集成，支持跨设备同步

### 4. UI设计
- 昆曲美学风格：淡青、米白、黛蓝、朱砂红配色
- 水墨渲染效果
- 响应式布局，适配不同屏幕

## 使用说明

### 开发环境配置

1. 配置云开发环境
   - 在 `miniprogram/app.js` 中设置 `env` 参数为你的云开发环境ID

2. 创建云数据库集合
   - `users`: 用户数据表
   - `quiz`: 题库表
   - `story`: 剧情节点表
   - `archives`: 学习档案表

3. 部署云函数
   - 在 `cloudfunctions/quickstartFunctions` 目录右键选择"上传并部署"

### 页面说明

- **主菜单** (`pages/menu/`): 游戏入口，提供开始游戏、继续游戏、学习档案、设置等功能
- **剧情页面** (`pages/story/`): 核心游戏体验，展示剧情对话和分支选择
- **问答页面** (`pages/quiz/`): 知识考验，答题并获取反馈
- **学习档案** (`pages/archive/`): 查看已解锁的角色和答题记录
- **设置页面** (`pages/settings/`): 音乐、文本速度、语言等设置
- **管理后台** (`pages/admin/`): 管理员功能（题库管理、剧情管理等）

## 技术特点

- **MVC架构**: 数据层、逻辑层、表示层分离
- **状态机设计**: 剧情流程通过状态机管理，易于扩展
- **云开发集成**: 使用微信云开发，无需独立服务器
- **优雅降级**: 云数据库未初始化时使用本地默认数据

## 扩展说明

### 添加新剧情

在 `utils/story.js` 的 `getDefaultStory()` 方法中添加新的剧情节点，或通过云数据库的 `story` 集合管理。

### 添加新题目

在 `utils/quiz.js` 的 `getDefaultQuiz()` 方法中添加新的题目，或通过云数据库的 `quiz` 集合管理。

### 自定义样式

所有页面的样式文件（`.wxss`）都遵循昆曲美学风格，可根据需要调整配色和布局。

## 注意事项

- 云数据库未初始化时，系统会使用本地默认数据，功能正常但无法跨设备同步
- 管理员密码默认设置为 `kunqu2024`，实际应用中应从服务器获取
- 部分功能（如图像识别）需要后续扩展实现
