# 第一幕剧情数据库总结

## 剧情概述

**第一幕：初入戏班**

玩家扮演一名初入昆山戏班的新学徒，在师父的引导下开始学习昆曲。通过观察环境、与师父和师姐互动，了解昆曲的基本知识。

---

## 剧情节点

### 1. 起始节点 (start)
- **文本**：师父将你带到排练厅，介绍你成为戏班一员
- **人物**：李师父（主）
- **选项**：
  - 仔细观察排练厅的环境 → 进入 observe 节点
  - 主动向师父请教 → 进入 ask_teacher 节点

### 2. 观察节点 (observe)
- **文本**：观察师姐金丽卿练习水袖
- **人物**：李师父（主）、金丽卿（次）
- **选项**：
  - 继续观察她的动作 → 获得理解值+2
  - 主动询问她是否不适 → 获得好感值+2，理解值+1

### 3. 请教节点 (ask_teacher)
- **文本**：向师父请教昆曲基础知识
- **人物**：李师父（主）
- **选项**：
  - 询问行当分类 → 进入问答节点
  - 询问水磨腔特点 → 进入问答节点

### 4. 问答节点 (quiz_hangdang)
- **类型**：问答
- **题目ID**：quiz_hangdang_1
- **跳转**：答完后进入 after_quiz_hangdang

### 5. 问答后节点 (after_quiz_hangdang)
- **文本**：师父讲解行当分类
- **人物**：李师父（主）
- **奖励**：理解值+1，积分+10

---

## 题目信息

### 题目ID: quiz_hangdang_1

**问题**：昆曲的行当分为哪五大类？

**选项**：
- A. 生、旦、净、末、丑 ✓
- B. 生、旦、净、末、小
- C. 生、旦、净、末、武
- D. 生、旦、净、末、老

**答案**：A

**解析**：昆曲行当分为生、旦、净、末、丑五大类，每一类都有其独特的表演特色和角色定位。生角多扮演男性角色，旦角多扮演女性角色，净角多扮演性格刚烈的角色，末角多扮演中老年男性，丑角则多扮演滑稽角色。

**分类**：hangdang（行当）
**难度**：简单
**积分**：10分

## 人物信息

### 1. 李师父（Master Li）

**基本信息**：
- 姓名：李德明
- 身份：班主/师父
- 年龄：五十余岁
- 角色类型：teacher

**外观描述**：
- 中等身材，面容慈祥
- 长须花白，目光温和而有神
- 常穿深色长衫，腰间系着一条素色腰带

**性格特点**：
- 温和慈祥，对弟子循循善诱
- 深谙昆曲之道，是昆山戏班的精神支柱

**背景故事**：
- 从艺三十余年，精通昆曲各个行当
- 尤其擅长生角和净角
- 年轻时曾在苏州、南京等地演出，声名远播

- 姓名：金丽卿
- 身份：旦角演员/师姐

**时代背景**：明朝万历年间

**地点**：昆山戏班排练厅

**环境描述**：
- 传统的昆曲班社，排练厅内古木书案陈设

- 角落里摆放着各种戏曲道具

**氛围**：宁静祥和，充满文人气息和艺术氛围

## 数据导入说明

### 云数据库集合

1. **story 集合** - 导入剧情节点
   - 文档：chapter1_data.json 中的 story_nodes 数组

2. **quiz 集合** - 导入题目
   - 文档：chapter1_data.json 中的 quiz 数组

3. **characters 集合** - 导入人物信息
   - 文档：chapter1_data.json 中的 characters 数组

### 导入步骤

1. 打开微信开发者工具
2. 进入云开发控制台
3. 选择对应的数据库集合
4. 导入 JSON 数据（使用 chapter1_data.json 中的对应数组）
